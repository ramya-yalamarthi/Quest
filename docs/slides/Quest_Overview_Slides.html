Quest — AI Support Agent

Support cases → grounded AI recommendations, written straight back into Dynamics 365 / ServiceNow
Business Value
~30–60s case → recommendation, 24/7 hands-off
Industries
Cloud Infra · ITSM · Enterprise Support
Build Status
MVP deployed · phased hardening
Problem

Engineers triage every case by hand — routing, root-cause hunting and fix research are slow, inconsistent, and repeat work already solved in past tickets.

Objective

Route, diagnose and recommend a fix on every case in ~30–60s — grounded in real case history — so engineers act instead of investigate.

Solution

A stateless orchestrator runs a Routing → Diagnosis → Recommendation → Mitigation pipeline on each case, posts one grounded note back to the case, and safely auto-remediates only low-risk, high-confidence issues — every decision audited.

Systems Integrated
Dynamics 365
ServiceNow
Azure OpenAI
MCP Tools
FEATURES
  • Event webhooks → dedupe → state machine
  • Skill- & shift-aware team / engineer routing
  • Similarity-grounded root-cause diagnosis (pgvector)
  • Hot Fix + Ultimate Fix with allowlisted links
  • Guarded auto-remediation: verify-then-revert + kill switch
  • Dual engine (legacy | MCP) + full audit trail
USE CASES
  • Kubernetes / Karpenter infra incidents auto-triaged
  • Reopened cases get an escalated recommendation
  • Manager SLA-risk dashboard for open tickets
  • 👍 / 👎 feedback regenerates an improved answer
  • Reusable MCP tools for Copilot Studio agents
BENEFITS
  • ~30–60s case → recommendation, hands-off 24/7
  • Grounded in real history — no hallucinated fixes
  • Graceful degradation — no single point of failure
  • Safety-first: suggests by default, acts only behind gates
  • Full auditability of every AI decision
